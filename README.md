# ApplySmart

ApplySmart prepares tailored job applications using a React frontend and Node.js/Express backend.

## Stack

- React + JavaScript
- Vite
- Node.js + Express
- Gemini API
- Tailwind CSS

## Run locally

1. Install dependencies:
   `npm install`
2. Set `GEMINI_API_KEY` in `.env.local`.
3. Start the development server:
   `npm run dev`

## Production

Build the frontend with:

`npm run build`

Start the Node.js server with:

`npm start`
